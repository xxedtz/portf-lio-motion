Gustavo Alves — Portfólio

Portfólio pessoal desenvolvido para apresentar projetos, habilidades e serviços relacionados ao desenvolvimento web e design digital.

Sobre

Este projeto reúne informações sobre minha atuação como desenvolvedor e designer, destacando competências técnicas, experiência em criação de interfaces e desenvolvimento de aplicações web.

O objetivo é demonstrar conhecimento em desenvolvimento front-end, experiência do usuário, design de interfaces e construção de produtos digitais.

Execução

Clone o repositório:

git clone https://github.com/xxedtz/portf-lio-motion.git

Acesse a pasta do projeto:

cd seu-repositorio

Abra o arquivo "index.html" no navegador ou utilize uma extensão como Live Server para desenvolvimento local.
